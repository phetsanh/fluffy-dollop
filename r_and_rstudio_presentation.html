2. What is R vs. RStudio?

The statistical engine vs. the IDE cockpit
R (The Engine)
  • Language: Open-source statistical computing language created by Ross Ihaka & Robert Gentleman in 1993.
  • Vectorized: Math operations naturally loop over datasets at internal C speed.
  • CRAN: Comprehensive R Archive Network with 20,000+ statistical packages.
# Type in console:
R.version.string
# [1] "R version 4.4.1 (2024-06-14)"
RStudio (The Cockpit)
  • IDE: Developed by Posit (formerly RStudio PBC) to provide a professional user interface.
  • Features: Source code editor, live workspace object explorer, plot previews, debugger, and Git integration.
  • Reproducibility: Manages R Projects (.Rproj) to avoid broken file paths.
🚗
Analogy: R is the engine under the hood. RStudio is the dashboard, steering wheel, and satellite GPS.

3. The 4 Quadrants of RStudio

How to navigate the interface like a pro
1. Top-Left: Source Editor (Ctrl+1)

Where you write and save your scripts (.R) and Quarto docs (.qmd). Code isn't executed until you send it.

# Press Ctrl+Enter to run:

2. Top-Right: Environment / History (Ctrl+8)

Lists all active variables, data tables, and objects in memory. Click any table to open the interactive data spreadsheet viewer.

# Environment shows:

3. Bottom-Left: Console & Terminal (Ctrl+2)

The interactive prompt (REPL). It displays calculation results, warnings, and messages sent from the source editor.

> x * 2
[1] 20 40 60
4. Bottom-Right: Files / Plots / Help

View your folder structure, preview ggplot figures, browse installed packages, and read documentation using ?function.

> ?summary # Opens help pane

4. R Projects (.Rproj) & Working Directories

Why setwd() is dangerous and how .Rproj fixes it
❌ The Anti-Pattern: Hardcoded Paths

Never do this in scripts:

# Breaks if anyone else runs it!
setwd("C:/Users/name/Desktop/project")
data <- read.csv("C:/data/test.csv")

If your collaborator runs this, or you move to a new laptop, every path crashes immediately.

✅ The Best Practice: R Projects & the 'here' package

Use File → New Project in RStudio:

library(here)
# Paths automatically anchor to project root:
data <- readr::read_csv(here("data", "raw.csv"))

The .Rproj file acts as a self-contained sandbox. Anyone can clone your repository and run it with 0 modifications.

⚡
Keyboard Shortcut: Insert the assignment arrow <- with Alt + - (Option + - on Mac).

5. Core Data Types in R

Numeric, Integer, Character, Logical, and Factors
Numeric & Integer

Numeric (doubles) are decimals. Integers end with L.

a <- 3.14 # numeric
b <- 42L # integer
typeof(a) # "double"
Character & Logical

Strings use quotes. Booleans are TRUE or FALSE.

str <- "Genomics"
flag <- TRUE
flag & (10 > 5) # TRUE
Factors (Categorical)

Data with fixed categories and levels.

size <- factor(
  c("S", "L", "M"),
  levels = c("S", "M", "L")
)
Special Missing Values: NA vs NULL

NA stands for Not Available (missing observation). NULL means an object does not exist. Always check with is.na(x), never x == NA!

6. Vectors: 1-Based Indexing & Vectorization

The heart of all operations in R
Atomic Vectors with c()
# Combine with c():
vals <- c(10, 25, 50, 75, 100)

# 1-Based Indexing:
vals[1] # 10 (First element!)
vals[2:4] # 25, 50, 75
vals[-1] # Omits first element
vals[vals > 30] # 50, 75, 100
Vectorization (No loops needed!)

Arithmetic applies to all elements simultaneously at C speed:

x <- c(1, 2, 3)
y <- c(10, 20, 30)

x + 5 # [1] 6 7 8
x * y # [1] 10 40 90
sqrt(y) # Applied to each number
⚠️
Type Coercion: A vector can hold only one data type. c(1, "hello") forces both to become strings.

8. The Native Pipe Operator (|>)

Write code that reads naturally from left to right
Old Style: Nested Function Spaghetti
# Read from inside out:
round(
  mean(
    filter(df, age > 30)$salary,
    na.rm = TRUE
  ),
  2
)
Modern Style: Native Pipe (|>)
# Read top-down ("and then"):
df |>
  filter(age > 30) |>
  pull(salary) |>
  mean(na.rm = TRUE) |>
  round(2)
⚡
Keyboard Shortcut: Press Ctrl + Shift + M to insert the pipe instantly. (Configure RStudio Options → Code → Use native pipe).

9. Data Wrangling with dplyr

The 5 core verbs for 95% of data processing tasks
filter()

Pick rows

filter(age >= 21)
select()

Pick cols

select(id, score)
mutate()

New cols

mutate(log_p=log(p))
arrange()

Sort rows

arrange(desc(p))
summarise()

Aggregate

summarise(m=mean(x))
Complete Real-World dplyr Pipeline:
library(dplyr)

summary_table <- starwars |>
  filter(!is.na(height), !is.na(mass)) |>
  mutate(bmi = mass / ((height / 100)^2)) |>
  group_by(species) |>
  summarise(
    n = n(),
    avg_bmi = mean(bmi),
    max_mass = max(mass)
  ) |>
  filter(n >= 2) |>
  arrange(desc(avg_bmi))

10. Reshaping Data with tidyr

Pivoting between Wide and Long formats
pivot_longer() • Wide to Long

Stacks repeated measurement columns into key-value pairs (essential for plotting with ggplot2):

# From: id | yr2020 | yr2021 | yr2022
long_df <- df |>
  pivot_longer(
    cols = starts_with("yr"),
    names_to = "year",
    values_to = "revenue"
  )
# Result: id | year | revenue
pivot_wider() • Long to Wide

Spreads key-value pairs out into new columns (ideal for presentation tables):

# From: patient | test_name | result
wide_df <- long_df |>
  pivot_wider(
    names_from = test_name,
    values_from = result
  )
# Result: patient | glucose | cholesterol

11. Data Visualization with ggplot2

The Grammar of Graphics: Constructing figures layer by layer
The 7 Layers of ggplot2
  • Data: The data frame (ggplot(df))
  • Aesthetics (aes): Mapping variables to x, y, color, size
  • Geometries: Shapes (geom_point, geom_line, geom_boxplot)
  • Scales: Colors, axis ranges (scale_y_log10)
  • Facets: Small multiples (facet_wrap(~ group))
  • Themes: Overall styling (theme_minimal())
Production-Ready ggplot2 Code
library(ggplot2)

ggplot(mpg, aes(x = displ, y = hwy, color = class)) +
  geom_point(size = 2.5, alpha = 0.8) +
  geom_smooth(method = "lm", se = FALSE) +
  scale_color_viridis_d() +
  labs(
    title = "Fuel Economy by Displacement",
    x = "Engine Displacement (L)",
    y = "Highway MPG"
  ) +
  theme_minimal(base_size = 12)

13. Functional Programming with purrr

Type-safe map functions replace brittle loops
Why replace for loops?

Loops in data analysis require setting up empty containers, tracking indices, and are vulnerable to off-by-one errors.

🎯
purrr::map_*() guarantees the exact return type or raises an informative error immediately.
The purrr Toolkit
library(purrr)

# Read & bind 100 CSVs into 1 table in one line:
combined <- files |> map_dfr(readr::read_csv)

# Type-specific vector mapping:
map_dbl(mtcars, mean) # Returns numeric vector
map_chr(df, class) # Returns character vector
map_lgl(df, anyNA) # Returns TRUE / FALSE vector

14. High Performance R: data.table

Blazing fast calculations on tens of millions of rows
The DT[i, j, by] Syntax

Pronounce as: "Take DT, filter rows with i, calculate j, grouped by by":

library(data.table)
DT <- as.data.table(flights)

# Ultra-fast aggregation:
DT[dest == "JFK",
   .(avg_delay = mean(arr_delay, na.rm = TRUE), count = .N),
   by = .(carrier, origin)]
Zero-Copy In-Place Updates (:=)

Standard R copies data on modify. := updates in place with 0 memory duplication:

# Instant new column without duplicating memory:
DT[, speed_mph := (distance / air_time) * 60]

# Multi-threaded file reading:
big_df <- fread("10GB_dataset.csv", nThread = 8)

15. Metaprogramming & C++ with Rcpp

Under the hood of the language and compiling machine code
Tidy Evaluation: The Embrace {{ }}

Write reusable custom functions accepting bare column names:

library(rlang)

my_summary <- function(df, group_col, num_col) {
  df |>
    group_by({{ group_col }}) |>
    summarise(mean = mean({{ num_col }}, na.rm = TRUE))
}

my_summary(mtcars, cyl, mpg)
C++ Acceleration with Rcpp

Embed compiled C++ directly into your R sessions:

library(Rcpp)

cppFunction('
int fibonacci(int n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
')

fibonacci(30) # Native compiled speed!

16. Reproducible Publishing: Quarto (.qmd)

The next-generation scientific publishing engine
Why Quarto?

Quarto weaves prose, code, and live outputs into professional documents:

  • Multi-Format: Export to HTML, PDF (LaTeX), Word, slides (reveal.js), or interactive dashboards.
  • Multi-Language: Execute R, Python, and SQL chunks in the same document.
  • Plain text: Fully version-controllable with Git.
Example Document (.qmd):

title: "Clinical Analysis Report"
format: html
execute:
  echo: true
